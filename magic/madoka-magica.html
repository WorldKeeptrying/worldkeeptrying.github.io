✧ 魔兽篇 剧情 ✧

官方外传漫画 全9话 / 3卷 TV版 → 叛逆的物语 之间

( ◕‿◕ )⚔( 👾 )

小圆成为「圆环之理」后，魔女被彻底消除。但取而代之的是全新的敌人——「魔兽」（Wraiths），它们以人类情感为食。

( ◕ᴗ◕ ) 沙耶香的复活

小圆的愿望从根本上消除了魔女的存在，沙耶香因此复活。她和麻美、杏子一起继续作为魔法少女讨伐魔兽。

( ಠ_ಠ ) 理念冲突

沙耶香复活后与杏子再次产生理念冲突。杏子对沙耶香的"正义感"和"自我牺牲"态度仍抱有复杂情感——两人曾在前一条世界线中同归于尽。

( ¬_¬ ) 焰的孤独

晓美焰是唯一保留完整记忆的人。她独自背负对小圆的思念，在沙漠中独自与魔兽作战，听到小圆对她喊"加油"的声音。

( 👾 ) 涅槃魔兽

最强魔兽「涅槃魔兽」出现。美树沙耶香在与其战斗中力竭而亡——这解释了TV结局中杏子提到的"沙耶香用尽力量消失了"。

( ╥_╥ ) 即使魔女不存在了，魔法少女仍会因灵魂宝石污染而死去…

→ 这为《叛逆的物语》中小焰的魔女化埋下伏笔 ( 🖤 )
